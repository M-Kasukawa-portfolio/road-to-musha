# 武者への道（架空・メディアサイト）

Hello Mentor 課題で制作した、駆け出しデザイナー・エンジニア向けの架空メディアサイトです。
Figmaのデザインカンプに基づきコーディングしました。

## Demo

https://mkdesignworks.net/portfolio/road-to-musha/

## 概要

- 内容: トップ／記事一覧／記事詳細／固定ページ／お問い合わせ／404 などの静的HTML
- 位置づけ: 学習課題（実務案件ではありません）
- 担当: コーディング（デザイン・レイアウト設計は含みません）
- 方針: カンプ準拠。レスポンシブはオーソドックスな実装

## 使用技術

HTML5 / Sass(SCSS) / JavaScript

## この課題で扱ったこと

メディアサイト特有の複数ページ構成（一覧・詳細・固定ページなど）を、
共通パーツとページ固有セクションに分けて実装しました。
PC／SPの画像・レイアウト切り替えを通じて、
カンプを正確に再現するときのブレイクポイントや出し分けの考え方を学びました。
